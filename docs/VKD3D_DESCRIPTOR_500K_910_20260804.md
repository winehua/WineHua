## Test Coverage

The test creates a 500,000-entry shader-visible CBV/SRV/UAV heap and verifies
that a 500,001-entry heap is rejected with `E_INVALIDARG`. It then:

1. Uploads a fixed 16-byte payload to a default buffer.
2. Places a raw SRV in descriptor slot 499,999.
3. Places a raw output UAV in descriptor slot 2.
4. Creates the descriptor-table root signature and compute pipeline.
5. Dispatches a shader which reads through `t4` from the last heap slot and
   writes through `u2`.
6. Copies the GPU output to a readback buffer and compares all 16 bytes.
7. Releases every D3D12 object and `d3d12.dll`, persists the final JSON, and
   only then prints the externally observable `FINAL` record.

The microtest contains no `vkDeviceWaitIdle`, `Sleep`, `sleep`, or global flush
compensation. Completion uses a D3D12 fence and event. The isolated runtime
keeps the already qualified coherent-map synchronization and query-meta
exclusion; neither setting is enabled for normal application launches.

## Decision

The isolated VKD3D-Proton 2.6 limited-500K profile passes the real final-slot
GPU descriptor access test three consecutive times on this 910 device for the
exact artifacts above. This is a descriptor follow-up gate, not general D3D12
or game qualification.

D3D12 remains default-off. DXVK Legacy and Modern payloads are unchanged. The
next gates remain BDA, multiple queues, BrokerPresent, a physical-display
1,000-frame run, full DXVK regression, and only then real DX12 game testing.
