## Test coverage

The test retains the qualified 500,000-entry descriptor path and adds a real
Buffer Device Address execution path. It:

1. Creates upload, default, BDA output, and readback buffers.
2. Requires non-zero GPU virtual addresses from `GetGPUVirtualAddress()`.
3. Binds those addresses through root SRV and root UAV descriptors.
4. Runs a compute shader that reads the input through GPUVA and writes the
   output through GPUVA.
5. Copies the BDA output into a distinct readback range and compares every
   byte with the expected payload.
6. Continues to access descriptor slot 499,999 and validates that result in the
   same run.
7. Completes through a D3D12 fence/event, tears every object down, writes the
   result JSON, and only then emits the final externally visible record.

The test contains no sleep, `vkDeviceWaitIdle`, or global-flush compensation.
The isolated runtime keeps the already qualified coherent-map synchronization
and query-meta exclusion; neither setting is enabled for normal launches.

## Decision

The isolated VKD3D-Proton 2.6 limited-500K profile passes the BDA follow-up
gate three consecutive times on this 910 device for the exact artifacts above.
This qualifies GPUVA root SRV/UAV addressing and byte-accurate execution; it is
not general D3D12 or game qualification.

D3D12 remains default-off. Multiple queues, BrokerPresent, and the full DXVK
regression remain mandatory before any real DX12 game test.
